# Polaris

Polaris is a self-hosted AI agent for running on your own computer or server.

## Build from source

Requirements: Go 1.26+, Rust stable, Node.js 24+, and the platform libraries required by Tauri and Wasmtime.

```sh
make build
```

The executable is written to `bin/polaris`. See the release page for ready-to-run packages and the installation instructions for your platform.
